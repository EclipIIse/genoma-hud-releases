# Genoma HUD — релизы

Здесь лежат только установщики Genoma HUD, HUD поверх The Isle Evrima для сервера GENOMA.

Установленный HUD сам находит новые версии: в режиме карты появляется «Доступна версия …» с кнопкой «Обновить». Каждый установщик подписан, и HUD ставит только файлы, подписанные автором.

Чтобы поставить HUD впервые, скачай `GenomaHUD_…_x64-setup.exe` из последнего релиза.
